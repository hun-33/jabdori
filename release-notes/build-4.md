# build-4 - 일요일 시작 달력과 카카오 로그인 확인

달력을 일요일부터 시작하도록 바꾸고, 카카오 로그인이 실제로 완료되었는지 단계별로 확인한 뒤 안내하도록 했습니다.

**배포일:** 2026-11-24

## 추가 (Added)
- 흉내 로그인으로 들어왔을 때 실제 카카오 인증이 아니라는 안내를 따로 표시하도록 추가했습니다.
- 나 탭에 로그인 상태(로그인 방식, 카카오 계정 연결, 앱 로그인 시각, 로그아웃 버튼)를 추가했습니다.
- 개발자용 로그인 진단 화면과 다시 확인 기능을 추가했습니다. 토큰 값은 화면에 표시하지 않습니다.
- 앱을 켜거나 다시 열 때 로그인이 유지되는지 확인하고, 만료되었으면 "로그인이 만료됐어요"로 안내하는 기능을 추가했습니다.
- 목소리 음량 설정과 상황별(시작·지각, 마감, 딴짓·공부 확인, 결과, 말풍선 변화) 켜고 끄기를 추가했습니다.

## 변경 (Changed)
- 주간·월간 달력, 반복 요일 칩, 주 이동 순서를 일요일부터 토요일까지로 변경했습니다.
- 카카오 인증, 토큰 확인, 사용자 정보, 회원 확인, 세션 저장이 모두 확인되었을 때만 "카카오 계정으로 로그인했어요!"를 표시하도록 변경했습니다.

## 제거 (Removed)
- 일반 화면에서 카카오 회원번호 표시를 제거했습니다. 회원번호는 개발자 진단 화면에서만 확인할 수 있습니다.

## 참고 사항 (Notes)
- 저장된 요일 값은 바뀌지 않으므로 이미 올린 일정의 날짜와 반복 요일은 그대로 유지됩니다.
- 캐릭터 녹음 파일을 재생하는 기능을 준비했으며, 이 빌드에는 녹음 파일이 포함되어 있지 않습니다.
