# build-3 - 미루먼지 농도와 목소리 설정 도입

잡도리 세기를 나타내는 이름을 온도에서 미루먼지 농도로 바꾸고, 목소리 설정과 휠 직접 입력을 추가했습니다.

**배포일:** 2026-11-24

## 추가 (Added)
- 나 탭에 단계 이름 설정을 추가했습니다. 캐릭터별(미루먼지 농도: 좋음·보통·나쁨·매우 나쁨·최악)과 공통(잡도리 강도: 순한맛·보통맛·매운맛·아주 매운맛·최고 매운맛) 중에서 고를 수 있으며, 바꾸면 모든 화면, 기록, 알림 확인 문구가 바로 새 이름으로 바뀝니다.
- 목소리 소리 모드(끄기·중요할 때만·모든 멘트)를 추가했습니다.
- 높은 단계(매우 나쁨·최악)에서 목소리가 조금 더 빠르고 높게 나오는 단계별 목소리를 추가했습니다.
- 말 빠르기(느리게·보통·빠르게)와 미루먼지 목소리 들어 보기를 추가했습니다.
- 한국어 음성이 기기에 없을 때 음성 설치 화면으로 안내하는 기능을 추가했습니다.
- 날짜·시각·길이 휠에서 18:30, 오후 6시 반, 90분, 내일, 12/3, 3일 뒤처럼 글자로 직접 입력하는 기능을 추가했습니다.

## 변경 (Changed)
- 잡도리 단계 이름을 온도(미지근·따끈·뜨끈·부글·펄펄)에서 미루먼지 농도(좋음·보통·나쁨·매우 나쁨·최악)로 변경했습니다. 0~100 숫자와 계산 방식은 그대로입니다.
- 바닥 온도를 쌓인 먼지로, 단계 해제를 먼지 털기로 이름을 변경했습니다. 실패 시 10 오르고 3번 연속 성공하면 한 단계 내려가는 규칙은 같습니다.

## 개선 (Improved)
- 같은 말을 15초 안에 다시 읽지 않고, 중요한 말을 읽는 동안 다른 멘트가 끼어들지 않도록 개선했습니다.
- 18:30을 "18시 30분"으로 읽는 등 시각과 기호를 자연스럽게 읽도록 개선했습니다.

## 수정 (Fixed)
- 휠을 빠르게 연달아 누르면 시작 시각이 00:00으로 바뀌던 문제를 수정했습니다.
- 새 일정 화면에서 종류·반복·달력을 누를 때마다 화면이 다시 내려왔다 올라오던 문제를 수정했습니다.
- 반복 요일 칩이 가운데로 정렬되지 않던 문제를 수정했습니다.

## 참고 사항 (Notes)
- 이전 빌드에서 "멘트 소리로 듣기"를 켜 두었다면 소리 모드가 "모든 멘트"로 자동 설정됩니다.
