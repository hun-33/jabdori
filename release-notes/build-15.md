# build-15 - 홈 화면 위젯, 새 일정 시간 칸 다듬기

앱을 열지 않아도 홈 화면에서 오늘 일정과 다음 일정을 보고 일반 일정을 체크할 수 있는 위젯 4종을 추가했습니다. 새 일정의 시간 칸도 더 단순하게 바꿨습니다.

**배포일:** 2026-11-25

## 추가 (Added)
- 홈 화면 위젯 '오늘의 일정'(4×2)을 추가했습니다. 오늘 날짜, 완료 수와 진행률, 앱 오늘 화면과 같은 순서의 일정 줄을 보여 줍니다. 일반 일정은 줄 앞 동그라미를 눌러 위젯에서 바로 완료하거나 취소합니다. 크기를 키우면 일정 줄이 늘고, 4×4 정도로 크게 하면 미루먼지 한마디도 보여 줍니다. 일정이 더 있으면 "+N개 더"를 눌러 앱에서 봅니다.
- 홈 화면 위젯 '다음 일정'(2×2)을 추가했습니다. 다음 일정 이름, 시작 시각, 시작까지 남은 시간(카운트다운)을 보여 주고, 지금 진행 중이거나 시작 전인 일정은 아래에 따로 보여 줍니다. 완료한 일정과 종일 일정은 다음 일정에서 뺍니다.
- 홈 화면 위젯 '미루먼지'(2×2, 4×2로 넓히면 가로 배치)를 추가했습니다. 앱 오늘 화면과 같은 계산으로 고른 표정, 기존 대사, 미루먼지 농도를 보여 줍니다.
- 홈 화면 위젯 '잡도리 통계'(2×2)를 추가했습니다. 오늘 완료율, 이번 주 잡도리 성공률(기록 탭과 같은 기준), 최근 기록부터 이어진 연속 성공 횟수를 보여 줍니다. 기록이 없으면 숫자 대신 안내 문구를 보여 줍니다.
- 설정 탭 > 홈 화면 위젯 화면을 추가했습니다. 위젯 4종 설명, 홈 화면에 놓인 수, 홈 화면에 바로 추가하는 버튼(홈 화면 앱이 지원할 때)이 있습니다.

## 변경 (Changed)
- 새 일정에서 시작 시각을 바꾸면 걸리는 시간을 그대로 두고 종료 시각도 함께 옮기도록 바꿨습니다. 예를 들어 18:00~19:00에서 시작을 19:00으로 바꾸면 종료가 20:00이 됩니다. 자정을 넘기면 종료 날짜도 넘어갑니다.
- 새 일정에서 날짜·시각을 한 번 누르면 달력·휠이 열리고, 열린 상태에서 한 번 더 누르면 직접 입력 창이 열리도록 바꿨습니다.
- 날짜 직접 입력에서 "/" 없이 숫자만 적어도 되도록 바꿨습니다. "12 18", "1218", "261218", "2026 12 18"을 받고, 숫자 자판이 뜹니다. "125"처럼 1/25와 12/5 둘 다 되는 경우에는 네 자리로 적어 달라고 안내합니다. 오늘·내일·모레(종료 날짜는 시작과 같은 날·다음 날) 버튼도 넣었습니다.
- 종료 날짜도 직접 입력할 수 있게 했습니다. 시작보다 앞선 날짜나 32일을 넘는 일정은 안내와 함께 막습니다.
- 종일을 켜면 시각 칸("종일 → 종일")을 없애고, 그 자리로 날짜 달력이 올라오도록 바꿨습니다.

## 참고 사항 (Notes)
- 위젯에서 체크한 일반 일정은 앱을 열거나 앱이 켜져 있을 때 기록에 반영됩니다. 같은 체크가 두 번 반영되지 않게 했고, 그사이 지워진 일정은 반영하지 않고 안내합니다.
- 잡도리 일정은 위젯에서 체크하지 않습니다. 누르면 앱이 열려 그 일정(진행 중이면 집중 화면)으로 갑니다.
- 위젯은 정확한 알람을 쓰지 않아서, 안드로이드 12 이상에서는 '예정 → 시작 전'처럼 시간이 지나 바뀌는 상태가 몇 분 늦게 바뀔 수 있습니다. 시작까지 남은 시간 카운트다운은 위젯이 스스로 흐릅니다.
- 폰이 어두운 모드면 위젯이 숯색 바탕으로 바뀝니다.
- 위젯 그리기와 크기별 배치는 GitHub 빌드에서 컴파일만 확인했고, 실제 폰 홈 화면에서는 아직 확인하지 않았습니다. 위젯에 넘기는 데이터, 체크 반영, 위젯에서 앱 열기는 안드로이드 흉내 검사로 확인했습니다.
- 아이폰 앱(ios-build-5)에는 새 일정 시간 칸 변경만 들어갔습니다. 홈 화면 위젯은 아이폰에 없습니다.
