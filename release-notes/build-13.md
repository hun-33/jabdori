# build-13 - 나 탭 이름을 설정으로

계정 상태와 설정 메뉴만 남은 나 탭의 이름을 설정으로 바꿨습니다.

**배포일:** 2026-11-25

## 변경 (Changed)
- 아래쪽 탭 이름을 "나"에서 "설정"으로, 아이콘을 사람 모양에서 조절 막대 모양으로 바꿨습니다.
- 설정 첫 화면의 제목 아래 문구를 "미루먼지와 앱을 내게 맞게 바꿔요"로, 메뉴 묶음 이름을 "앱 설정"으로 바꿨습니다.
- 앱 안내 문구에서 앱 설정 위치를 가리킬 때 휴대폰 설정과 헷갈리지 않도록 "설정 탭 > 목소리"처럼 적도록 바꿨습니다.

## 참고 사항 (Notes)
- 아이폰 앱(ios-build-3)에도 같은 변경이 들어갔습니다.
