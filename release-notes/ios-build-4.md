# ios-build-4 - 시연 도구 정리, 숨은 개발자 메뉴, 도장 문구

시연 도구와 한 줄로 쓰기를 지우고, 로그인 진단을 숨은 개발자 메뉴로 옮겼습니다.

**배포일:** 2026-11-25

## 추가 (Added)
- 숨은 개발자 메뉴를 추가했습니다. 설정 탭 첫 화면 맨 아래 작은 글씨를 2초 안에 7번 누르면 개발자 > 로그인 진단이 나타나고, 다시 7번 누르면 숨습니다.

## 변경 (Changed)
- 잡도리 일정 결과 도장 문구를 성공은 "훌륭해!", 실패는 "아쉽네!"로 바꿨습니다.
- 발표용 시연 도구(오른쪽 시연 탭, 가상 시각, 흉내 로그인, 딴짓 시뮬레이션, 테스트 데이터)와 설정 탭 > 화면의 "발표용 시연 도구 보이기"를 지웠습니다. 앱은 실제 시각으로 동작합니다.
- 새 일정 화면의 "한 줄로 쓰기"와 제목 칸의 예시 글씨("예: 데이터베이스 과제")를 지웠습니다.

## 참고 사항 (Notes)
- 안드로이드 앱(build-14)과 같은 화면 코드입니다. build-14의 지켜볼 앱 화면과 딴짓 앱 위 미루먼지 창은 아이폰에 해당하지 않습니다. Apple이 다른 앱 사용을 알 수 없게 막아 두어 아이폰은 딴짓 감지를 쓸 수 없습니다.
- 이번 변경은 아이폰 앱을 흉내 낸 화면 검사로 확인했습니다.
