# build-14 - 지켜볼 앱 고르기, 딴짓 앱 위 미루먼지 창, 시연 도구 정리

딴짓 감지에서 이 폰의 앱 중 지켜볼 앱을 고르고, 딴짓 앱 위에 뜨는 미루먼지 창에서 바로 답하도록 했습니다. 시연 도구와 한 줄로 쓰기는 지웠습니다.

**배포일:** 2026-11-25

## 추가 (Added)
- 설정 탭 > 알림·딴짓 감지 > 지켜볼 앱 화면을 추가했습니다. 이 폰의 앱 서랍에 보이는 앱을 아이콘·이름·분류(동영상, SNS, 게임 등)와 함께 모두 보여 주고, 줄마다 스위치로 지켜볼지 정합니다. 앱 이름으로 찾을 수 있습니다.
- 잡도리 중에 지켜보는 앱을 정해 둔 시간 넘게 쓰면, 잡도리 앱으로 넘기지 않고 그 앱 위에 미루먼지 창을 띄우도록 했습니다. 진행 중이면 "공부 중이야"(10분 동안 조용히), "잠깐 쉴게"(5분 휴식), "다시 집중할게", 시작 전이면 "지금 시작할게"(잡도리를 시작하고 잡도리 앱 열기), "조금만 있다가"를 고를 수 있고, 고른 답은 그 잡도리 기록에 남습니다.
- 숨은 개발자 메뉴를 추가했습니다. 설정 탭 첫 화면 맨 아래 작은 글씨를 2초 안에 7번 누르면 개발자 > 로그인 진단이 나타나고, 다시 7번 누르면 숨습니다.

## 변경 (Changed)
- 잡도리 일정 결과 도장 문구를 성공은 "훌륭해!", 실패는 "아쉽네!"로 바꿨습니다.
- 지켜볼 앱의 이름을 폰에 보이는 앱 이름(예: YouTube)으로 맞췄습니다. 설정 화면, 알림, 미루먼지 창이 같은 이름을 씁니다.
- '다른 앱 위에 표시'를 허용하지 않았으면 전처럼 알림으로 알리고, 잡도리 앱을 열 때 앱 안 팝업으로 묻습니다. 잡도리 화면을 딴짓 앱 앞으로 가져오던 동작은 쓰지 않습니다.
- 발표용 시연 도구(오른쪽 시연 탭, 가상 시각, 흉내 로그인, 딴짓 시뮬레이션, 테스트 데이터)와 설정 탭 > 화면의 "발표용 시연 도구 보이기"를 지웠습니다. 앱은 실제 시각으로 동작합니다.
- 새 일정 화면의 "한 줄로 쓰기"와 제목 칸의 예시 글씨("예: 데이터베이스 과제")를 지웠습니다.

## 참고 사항 (Notes)
- 지켜볼 앱 화면, 미루먼지 창, 창에서 고른 답 반영은 안드로이드 앱을 흉내 낸 화면 검사로 확인했습니다. 실제 폰에서는 아직 확인하지 않았습니다.
- 지켜볼 앱 목록은 앱 서랍(홈 화면 앱 목록)에 보이는 앱만 보여 줍니다.
- 검사에 쓰던 가상 시각·테스트 일정 기능은 앱에서 빼서 검사 전용 파일(tools/test_hooks.js)로 옮겼습니다.
- 아이폰 앱(ios-build-4)에도 시연 도구 정리, 한 줄로 쓰기 삭제, 도장 문구, 숨은 개발자 메뉴가 들어갔습니다. 지켜볼 앱 화면과 미루먼지 창은 딴짓 감지가 되는 안드로이드에만 해당합니다.
