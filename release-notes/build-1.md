# build-1 - 잡도리 안드로이드 앱 첫 빌드

웹으로 만든 잡도리 화면을 안드로이드 앱(Capacitor)에 넣고, 카카오 로그인·알림·음성을 안드로이드 기능으로 연결한 첫 빌드입니다.

**배포일:** 2026-11-24

## 추가 (Added)
- 카카오 공식 SDK로 카카오톡을 열어 로그인하고, 카카오 동의 화면에서 동의한 정보(닉네임·프로필 사진·이메일)를 받아오는 기능을 추가했습니다.
- 앱이 꺼져 있어도 일정 시작·마감 때 미루먼지 말투로 폰 알림을 보내는 기능을 추가했습니다.
- 미루먼지 멘트를 폰의 음성으로 읽어 주는 기능을 추가했습니다.
- 로그아웃과 카카오 연결 끊기 기능을 추가했습니다.
- 안드로이드 뒤로 가기로 메뉴, 창, 결과, 집중 모드를 차례로 닫는 동작을 추가했습니다.
- 미루먼지 앱 아이콘과 시작 화면을 추가했습니다.

## 참고 사항 (Notes)
- build-1과 build-2는 앱 코드가 같아, 남아 있던 APK 하나를 두 릴리스에 함께 넣었습니다.
