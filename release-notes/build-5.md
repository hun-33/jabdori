# build-5 - 일정 구조 개편과 일/주/월 달력

일정을 시작·종료 일시 기준으로 다시 구성하고 일/주/월 달력과 하나의 등록 화면을 도입했습니다. 미루먼지 그림과 말투도 디자인 기준에 맞춰 새로 바꿨습니다.

**배포일:** 2026-11-24

## 추가 (Added)
- 일정에 시작 날짜·시각과 종료 날짜·시각을 따로 정하는 기능을 추가했습니다. 종일 일정과 여러 날 일정(최대 32일)을 만들 수 있습니다.
- 반복에 매월·매년을 추가했고, 매주·매월·매년도 간격(n마다)을 정할 수 있도록 했습니다.
- 일정 알림(정각, 5분·10분·30분·1시간·하루 전)을 여러 개 고를 수 있는 기능을 추가했습니다. 정한 시각에 폰 알림이 옵니다.
- 일정 색상 6가지와 메모(200자)를 추가했습니다.
- 잡도리 일정에 선택형 마감(없음, 종료 = 마감, 따로 정하기)을 추가했습니다.
- 잡도리 일정을 고칠 때 잡도리를 끄고 일반 일정처럼 둘 수 있는 기능을 추가했습니다.
- 달력 탭에 일간 시간표를 추가했습니다. 시작 칸과 끝 칸을 차례로 눌러 일정을 올릴 수 있습니다.
- 월간 달력에서 시작 날과 끝 날을 눌러 기간 일정을 올리는 기능을 추가했습니다.
- 달력을 옆으로 쓸어 넘기는 기능과 오늘로 돌아가는 버튼을 추가했습니다.
- 미루먼지 표정 3가지(당황, 부끄러움, 지침)와 단계가 오르면 늘어나는 먼지 입자 효과를 추가했습니다.

## 변경 (Changed)
- 일정 등록을 하나의 화면으로 변경했습니다. 처음에는 제목·종류·시작·종료·종일만 보이고, 상세 설정을 펼치면 반복·알림·색상·메모·강도·마감을 정합니다.
- 걸리는 시간과 끝 시각을 따로 입력하던 방식을 종료 일시 하나로 변경했습니다. 걸리는 시간 버튼은 종료를 빠르게 정하는 용도로만 남았습니다.
- 마감을 종료 시각에 맞출 때 같은 값을 다시 입력하지 않고 "종료 = 마감"을 한 번 누르도록 변경했습니다.
- 여러 곳에 있던 일정 추가 버튼을 오늘·달력 화면 오른쪽 아래의 + 버튼 하나로 합쳤습니다.
- 주간·월간 이동 버튼을 보기와 상관없이 한 벌로 합쳤습니다.
- 미루먼지를 누르면 메뉴 대신 짧은 반응과 목소리가 나오도록 변경했습니다.
- 미루먼지 그림을 디자인 시트 기본형(넓고 납작한 솜뭉치, 손그림 선, 점 눈, ω 입)으로 다시 그렸습니다. 단계가 올라가도 모양은 유지되고 최대 6%까지만 커집니다.
- 모든 대사와 배너·폰 알림 문구를 먼지 캐릭터 말투로 변경했습니다.

## 제거 (Removed)
- 캐릭터 메뉴와 그 안의 월간 달력 창, 농도 정하기 메뉴를 제거했습니다. 같은 기능은 달력 탭과 등록 화면의 상세 설정에서 사용할 수 있습니다.
- 오늘 탭에서 아래로 쓸어 월간 달력을 여는 동작을 제거했습니다. "달력에서 보기"로 달력 탭을 엽니다.
- 옷장, 코스튬(토끼·마법사·천사·악마형), 온보딩의 모습 고르기, 단계별 변신을 제거했습니다. 미루먼지는 항상 기본 모습으로 표시됩니다.

## 참고 사항 (Notes)
- 이전 빌드에서 올린 일정(날짜, 시작, 걸리는 시간)은 앱을 열 때 시작·종료 일시로 자동 변환됩니다. 일정 하나를 변환하지 못하더라도 나머지 데이터는 유지됩니다.
- 이전에 고른 코스튬 설정은 저장되어 있지만 화면에는 반영되지 않습니다.
