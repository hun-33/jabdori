# ios-build-1 - 아이폰 앱 첫 빌드

안드로이드 앱과 같은 화면과 기능을 아이폰에서도 쓸 수 있도록 아이폰 앱을 처음 만들었습니다.

**배포일:** 2026-11-25

## 추가 (Added)
- 아이폰 앱(iOS 15 이상)을 추가했습니다. 화면과 일정·달력·미루먼지 농도·기록은 안드로이드 앱과 같은 코드를 씁니다.
- 아이폰에서도 카카오 로그인을 할 수 있도록 카카오 iOS SDK로 로그인 기능을 만들었습니다. 카카오톡이 있으면 카카오톡으로, 없으면 카카오계정으로 로그인합니다.
- 시작·지각·마감 알림을 아이폰 알림으로 받을 수 있도록 했습니다.
- 미루먼지 녹음 목소리와 기기 음성 읽기를 아이폰에서도 쓸 수 있도록 했습니다.
- 앱 아이콘과 시작 화면을 안드로이드와 같은 미루먼지 그림으로 넣었습니다.

## 참고 사항 (Notes)
- 아이폰에서는 딴짓 감지(실제 앱 사용 감지)를 쓸 수 없습니다. Apple이 앱끼리 어떤 앱을 여는지 알 수 없게 막아 두었기 때문이며, 나 탭에 안내를 표시합니다. 시연 도구의 딴짓 시뮬레이션은 쓸 수 있습니다.
- 이 파일은 서명하지 않은 .ipa입니다. Windows PC에서 Sideloadly로 자기 Apple ID로 서명해 설치하며, 무료 Apple ID로 설치하면 7일마다 다시 설치해야 합니다.
- 카카오 로그인을 쓰려면 카카오 디벨로퍼스의 네이티브 앱 키에 iOS 번들 ID com.jabdori.app을 등록하고, Sideloadly에서 Use automatic bundle ID를 끄고 설치해야 합니다.
- 아직 실제 아이폰에서 확인하지 않은 빌드입니다.
