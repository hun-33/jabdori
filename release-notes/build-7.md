# build-7 - 삼성 캘린더 방식의 일정 등록 화면

**배포일:** 2026-11-25

## 추가 (Added)
- 등록 화면 안에 달력을 추가했습니다. 시작 날짜를 고르면 끝 날짜 선택으로 넘어가고, 시작부터 끝까지가 하나의 띠로 표시됩니다.
- 등록 화면 달력을 옆으로 쓸어 다른 달로 넘기는 기능을 추가했습니다. 새 일정에서는 지난 날짜를 고를 수 없습니다.

## 변경 (Changed)
- 시작과 종료를 한 줄에 나란히 놓고, 날짜와 시각을 각각 눌러 정하도록 변경했습니다.
- 시각 휠은 시각을 눌렀을 때만 열리도록 변경했습니다.
- 화면 위쪽의 닫기(X) 버튼 대신 아래쪽에 취소·저장 버튼을 두도록 변경했습니다.

## 개선 (Improved)
- 종료를 직접 입력할 때 기간(최대 31일)이나 시각으로 쓸 수 있도록 개선했습니다.
- 시작 날짜를 바꾸면 일정 기간이 그대로 유지되도록 개선했습니다.
