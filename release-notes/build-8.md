# build-8 - 월간 달력 여러 날 일정 표시와 종일 버튼 수정

**배포일:** 2026-11-25

## 추가 (Added)
- 한 주에 일정이 3줄을 넘으면 해당 날짜에 남은 개수를 +N으로 표시하는 기능을 추가했습니다.

## 변경 (Changed)
- 월간 달력에서 여러 날 일정을 날짜 칸마다 끊어 그리지 않고 하나로 이어진 막대로 표시하고 제목을 막대 가운데에 두도록 변경했습니다.
- 여러 날 일정이 다음 주로 넘어가면 다음 주 줄에서 막대를 다시 시작하고 제목을 다시 표시하도록 변경했습니다.
- 일정 막대 위를 눌러도 그 아래 날짜가 선택되도록 변경했습니다.
- 목록의 여러 날 일정 시각 표기를 "18:00–20:00(+4)"에서 "18:00 – 12월 1일 20:00"으로 변경했습니다.

## 수정 (Fixed)
- 종류가 "미루먼지 잡도리"일 때 종일 버튼이 눌리지 않던 문제를 수정했습니다. 새 일정에서 켜면 일반 일정으로, 이미 올린 잡도리 일정에서 켜면 잡도리가 꺼지며 그 이유를 버튼 아래에 안내합니다.
