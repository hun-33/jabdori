# ios-build-2 - 화면 다듬기: 농도 이름 정리, 기록 요약, 나 탭 나누기, 한 줄로 일정 쓰기

화면을 둘러보며 헷갈리거나 불편했던 곳을 정리하고, 기록 탭에 내 미루는 습관을 보여 주는 요약을 넣었습니다.

**배포일:** 2026-11-25

## 추가 (Added)
- 기록 탭 맨 위에 이번 주 요약(해낸 비율, 완료·실패 수)과 최근 4주 완료·실패 막대를 추가했습니다.
- 기록 탭에 "자주 미루는 때"를 추가했습니다. 잡도리 기록이 3개 이상이면 평균 시작 지각, 자주 밀리는 요일과 시간대(아침·낮·저녁·밤), 최근 4주 딴짓 횟수와 자주 연 앱, 자주 고른 실패 이유를 보여 줍니다.
- 새 일정 화면 맨 위에 "한 줄로 쓰기"를 추가했습니다. "내일 3시 과제 2시간", "매주 화요일 7시 스터디 1시간 반"처럼 적고 채우기(또는 엔터)를 누르면 제목·날짜·시작 시각·끝 시각·반복을 채웁니다. 적는 동안 어떻게 채워질지 미리 보여 줍니다.
- 월간 달력의 고른 날짜 줄에 "이 날 일정" 버튼을 추가했습니다.

## 변경 (Changed)
- 오늘 화면의 큰 숫자 이름을 항상 "미루먼지 농도"로 하고, 옆에 지금 상태(쉬는 중, 시작 전, 지금)를 붙이도록 바꿨습니다. 전에는 맡은 일이 없을 때 같은 자리에 "쌓인 먼지"가 표시됐습니다.
- 농도 용어를 정리했습니다. 실패로 쌓이는 칸은 "쌓인 먼지"(한 겹에 +10), 새 잡도리가 시작하는 값은 "시작 농도", 실패가 없을 때의 시작 값은 "기본 농도"로 부릅니다. 공통 단계 이름에서는 "최저 강도"를 "시작 강도"로 바꿨습니다.
- 나 탭 첫 화면을 계정 상태와 설정 메뉴(미루먼지 농도, 목소리, 알림, 화면, 계정 관리)로 줄이고, 각 설정은 눌러서 들어가는 화면으로 나눴습니다.
- 로그인 진단은 나 > 화면에서 "발표용 시연 도구 보이기"를 켜면 나 첫 화면에 나타나도록 했습니다.
- 달력 제목 아래의 조작 설명 문장을 지금 보이는 범위의 일정 수로 바꿨습니다. 일간 시간표 위의 안내는 그대로 둡니다.
- 월간 막대의 제목은 그대로 두고, 말줄임표 대신 끝을 흐리게 잘라 한두 글자 더 보이도록 했습니다.
- 기록 탭의 전체 완료·실패 수를 "지난 잡도리" 제목 옆으로 옮겼습니다.

## 수정 (Fixed)
- 짧은 안내 문구가 오른쪽 아래 + 버튼을 덮던 문제를 고쳤습니다. 이제 + 버튼 왼쪽에 뜹니다.
- 다른 화면으로 옮긴 뒤에도 지난 화면의 짧은 안내 문구가 남아 있던 문제를 고쳤습니다.
- 주간 달력의 "비어 있음" 글씨와 입력 칸의 예시 글씨가 흐려서 읽기 어렵던 문제를 고쳤습니다.

## 참고 사항 (Notes)
- 안드로이드 앱(build-12)과 같은 변경입니다. 아이폰에서는 나 첫 화면의 메뉴 이름이 "알림"이고, 딴짓 감지는 그 안에 안내만 표시합니다.
- 홈 화면 위젯처럼 앱 밖에서 미루먼지를 보여 주는 기능은 이번 빌드에 넣지 않았습니다.
