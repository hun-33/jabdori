# build-18 - 폼 달력 기간 다시 고르기, 달력 머리의 입력 버튼 지움

새 일정 폼 달력에서 기간을 다 고른 뒤 날짜를 다시 누르면 처음부터 새 기간을 고르도록 바꿨습니다. 달력 머리의 '입력' 버튼은 지웠습니다.

**배포일:** 2026-11-25

## 변경 (Changed)
- 폼 달력에서 시작 날짜와 끝 날짜를 다 고른 뒤 날짜를 다시 누르면, 그 날을 새 시작 날짜로 하고 처음부터 기간을 고르도록 바꿨습니다. 예를 들어 25일 → 28일을 누르면 25~28일이고, 이어서 26일을 누르면 26일 하루로 새로 시작하며, 28일을 누르면 26~28일이 됩니다. 이전에는 이어서 누른 날이 끝 날짜로만 바뀌어 25~26일이 됐습니다.
- 달력에서 시작 날짜를 새로 누르면 끝 날짜를 고르기 전까지 그 날 하루로 보이도록 바꿨습니다. 이전에는 시작 날짜를 옮기면 기간 길이를 그대로 두고 끝 날짜도 같이 옮겼습니다.
- 폼 달력 머리(연월 옆)의 '입력' 버튼을 지웠습니다. 날짜 직접 입력은 위의 시작·종료 날짜 버튼을 한 번 더 누르면 열립니다.

## 참고 사항 (Notes)
- 끝 날짜를 고를 차례에 시작 날짜보다 앞 날짜를 누르면 이전처럼 그 날부터 하루 일정으로 다시 시작합니다.
- 이번 변경은 화면 검사로 확인했고, 실제 폰에서는 아직 확인하지 않았습니다.
- 아이폰 앱(ios-build-7)에도 같은 변경이 들어갔습니다.
