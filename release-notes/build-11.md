# build-11 - 달력 날짜 다시 누르기로 새 일정, 이메일 동의 항목 제거

**배포일:** 2026-11-25

## 추가 (Added)
- 월간·주간 달력에서 고른 날짜를 한 번 더 누르면 그 날짜로 새 일정 화면이 열리는 기능을 추가했습니다. 지난 날짜는 새 일정 대신 안내가 표시됩니다.

## 변경 (Changed)
- 달력 위 안내 문구를 보기별로 변경했습니다. 일간은 "빈 시간 칸을 두 번 누르면 새 일정", 주간·월간은 "고른 날짜를 한 번 더 누르면 새 일정"으로 표시합니다.

## 제거 (Removed)
- 카카오계정(이메일) 동의 항목과 나 탭의 "이메일 제공에 동의하기" 버튼, 프로필의 이메일 표시를 제거했습니다. 이메일 동의항목 권한이 없어 이메일을 받지 않습니다.
